# Marriage Restoration Blueprint - Couples Recovery App

A comprehensive marriage restoration application providing couples with biblical tools, practical exercises, and structured guidance for rebuilding trust, improving communication, and restoring love in their relationship.

## ✨ Features

### Core Functionality
- **Marriage Health Assessment** - 12-area evaluation with visual scoring and feedback
- **30-Day Couples Devotional** - Daily scripture, content, prayers, and reflection questions
- **Forgiveness Exercises** - 4-stage structured forgiveness process
- **PEACE Conflict Resolution** - Template-based healthy disagreement method
- **5 Levels of Intimacy** - Comprehensive rebuilding guides for all intimacy areas
- **Progress Tracking** - Visual meters, statistics, and milestone celebrations
- **Crisis Support** - Emergency resources and professional help guidance
- **Marriage Resources** - Communication guidelines, love languages, weekly meetings

### Assessment Areas
- Communication
- Trust
- Intimacy
- Conflict Resolution
- Shared Goals
- Respect
- Friendship
- Support
- Forgiveness
- Spiritual Connection
- Fun & Recreation
- Commitment

### Technical Features
- Single HTML file application
- Local storage for data persistence
- Elegant, professional design
- Mobile-responsive layout
- Offline functionality
- Privacy-focused (all data stays local)
- Visual progress indicators
- Animated scoring system

## 🌟 Key Features Explained

### PEACE Conflict Resolution Method
- **P**ause & Pray - Take time to calm down and seek wisdom
- **E**xpress Feelings - Share using "I feel" statements
- **A**cknowledge & Validate - Repeat back and validate feelings
- **C**reate Solutions Together - Brainstorm as a team
- **E**stablish Agreement - Commit to specific actions

### 5 Levels of Intimacy
1. **Emotional** - Sharing feelings and vulnerabilities
2. **Intellectual** - Meaningful conversations and ideas
3. **Spiritual** - Faith, values, and purpose connection
4. **Recreational** - Fun and joyful activities together
5. **Physical** - Affectionate and sexual connection

### Forgiveness Process
1. Acknowledge the hurt without blame
2. Take responsibility for your part
3. Choose to forgive and release
4. Rebuild with new boundaries and agreements
